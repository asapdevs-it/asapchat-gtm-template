Walidację robią reguły pól szablonu. GTM nie zapisze tagu z błędną wartością. Kod tagu sprawdza wartości jeszcze raz i przy błędzie kończy się statusem „Failed”.
Szablon nie ma pól opóźnienia ani wykluczeń. Robisz to regułami GTM, tak jak dla każdego innego tagu.

Reguły

◷
AsapChat, po 5 sekundach
Licznik czasu · interwał 5000 ms · limit 1 · Page Path nie zawiera /cart
Wyjątki
◉
Koszyk
Wyświetlenie strony · Page Path zawiera /cart (działa tylko z regułą „Wyświetlenie strony”)

Jak to ustawić

  • Opóźnienie: zamiast All Pages dodaj regułę typu „Licznik czasu”. Interwał w milisekundach, limit 1.
  • Wykluczenia bez opóźnienia: dodaj wyjątek typu „Wyświetlenie strony” z warunkiem na Page Path.
  • Wykluczenia z opóźnieniem: warunek na Page Path wpisz w samej regule „Licznik czasu”. Wyjątek typu „Wyświetlenie strony” nie zatrzyma licznika.
